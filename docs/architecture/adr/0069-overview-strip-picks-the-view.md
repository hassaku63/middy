# 0069. 縮小図の帯は見る場所を選ぶ道具にする

- 日付: 2026-11-12
- 状態: Accepted（所有者の判断。ADR-0067 の 11 と、ADR-0068 の 3 のうち帯の部分を置き換える）

## 文脈

ADR-0067 の 11 で、帯を押すと再生位置が動くようにした（BL-330）。ADR-0068 の 3 では、帯を押すと、止めていた追随にも戻るようにした。

所有者は、操作を「状態（停止中・再生中）× 対象（帯・本体）」に分けて見直した。主な DAW の全体表示も参考にした（検索結果の要約で確かめた範囲）。

- Ableton の Arrangement Overview: 枠を横にドラッグするとスクロールし、縦にドラッグするとズームする。再生位置は、本体を押して決める。
- Cubase の Overview Line: 四角を左右にドラッグするか、帯の上部を押すと、表示が動く。端をドラッグするとズームする。

どちらも、全体表示は「見る場所を動かす道具」で、再生位置は動かさない。帯は縮尺が小さいので、細かい位置は選べない。

本体の再生位置の線をドラッグする案も検討した。再生中は線が動き続けるのでつかみにくく、採らなかった。

## 決定

1. **帯は見る場所だけを動かす。** 停止中も再生中も同じにする。再生位置は動かさない。
   - 枠をドラッグすると、本体のスクロールがそれに連動する（BL-331）。
   - 枠の外を押すと、押した位置へ枠を移し、本体もそこへスクロールする（BL-333）。これは、ドラッグの代わりになる、押すだけの操作も兼ねる（WCAG 2.5.7）。
2. **再生中に帯を操作すると、手でスクロールしたのと同じに扱う。** 追随を一時停止し、「再生位置へ戻る」を出す（ADR-0068）。帯を押しても、追随には戻らない。
3. **本体は今のまま。**
   - 和音以外を押すと、再生位置が動く（ADR-0067）。
   - 和音を押すと、固定する。
   - 再生位置の線のドラッグは作らない。

## 検討した選択肢

- 帯を押したとき
  - A: 見る場所だけ動かす（採用）。DAW と同じで、細かい位置を要しない。
  - B: 再生位置を動かす（今の BL-330）。縮尺が小さく、狙った拍に置きにくい。DAW と逆。
  - C: 何もしない。押すだけで済む代わりの操作がなくなる。
- 本体で再生位置を動かす方法
  - A: 和音以外のクリック（採用。今のまま）。
  - B: 線のドラッグを足す。再生中は線が動き続けて、つかみにくい。

## 結果

- 帯は「どこを見るか」、本体は「どこから鳴らすか」と、役割が分かれる。
- 帯の上のポインタの操作は、押すかドラッグかを、動いた距離で見分ける必要がある。
- 再検討の条件:
  - 帯から再生位置を動かしたい、という声が出たとき。
  - 例が長くなり、帯の枠が小さくてつかめなくなったとき。
