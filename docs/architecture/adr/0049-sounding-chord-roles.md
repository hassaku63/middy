# 0049. モードの和音の役割は、解説では鳴っている和音で決める

- 日付: 2026-11-10
- 状態: Accepted（ADR-0047 の一部を改める）

## 文脈

ADR-0047 は、モードの和音の役割を度数の三和音で決めた。解説の文も同じ役割から組み立てていた。その結果、七の和音で事実と違うことを言っていた（#371 の C3）。

- D ドリアンの IV7（G7 = G B D F）に「三全音を含まない特徴和音」と言っていた。G7 は、vi° が含むのと同じ三全音（F と B）を含む。
- E フリジアンの III7（G7）を「そのほか」とし、特徴音の F で「暗く、張りつめて聞こえる」と言っていた。G7 → Cmaj7 は、C major の V7 → I と同じ音になる。

また、ADR-0047 の「主和音へ戻る力は、特徴音が根音にあるときがいちばん強い」は、出典を確かめていなかった。

## 決定

- 解説（`Analysis.Role` と文）の役割は、鳴っている和音で決める（`soundingRole`）。度数の役割が特徴和音かそのほかでも、鳴っている和音が音階の三全音の 2 音を含めば、三全音の和音にする。主和音は、何を足しても主和音のまま。
- 七の和音で三全音ができたときの文: 「7 度の音を足すと三全音（F と B）ができるので、同じ音でできた C major に引き寄せられやすく、ドリアンの中心がぼやける。三和音の IV（G）のほうがドリアンらしく聞こえる。」。特徴音の一文は付けない（三全音の和音と同じ扱い）。
- 度数の地図（`DegreeChord.Role`）は、三和音の役割のまま（ADR-0048）。地図は調の 7 つの三和音を並べるものだから。
- 特徴音が根音にある特徴和音の一文は、「主和音へ戻る終わり方によく使われる」に弱める。ミクソリディアンの ♭VII → I、フリジアンの ♭II → i が、よく使われる終わり方であることは、多くの解説が一致している。強さの順位は、原典で確かめるまで言わない。

## 検討した選択肢

- モードで、三全音のできる七の和音を検証で拒む: ドリアンの i7 – IV7 はよく使う形で、拒むより説明するほうが学びになる。
- 役割は三和音のままにして、文だけ直す: 札（「特徴和音」）と文（「中心がぼやける」）が食い違う。
- 地図も鳴っている和音で決める: 地図は調の三和音の一覧で、例ごとに和音の形が変わると、同じ調の地図が例によって変わってしまう。

## 結果

- 七の和音でも、解説が事実と食い違わない。
- 解説の札と地図の列が食い違うことがある（IV7 は札が「三全音の和音」、地図では IV が「特徴和音」の列）。文が理由（三和音の IV との違い）を言うので、矛盾ではない。
