# 0071. 押したまま動かすと、再生位置がついてくる

- 日付: 2026-11-12
- 状態: Proposed（所有者の評価待ち）

## 文脈

ADR-0067 で、タイムラインの本体の和音以外を押すと、再生位置が拍の頭へ動くようにした。ADR-0069 では、再生位置の線そのものをドラッグする案を採らなかった。再生中は線が動き続けて、つかみにくいからである。

所有者からの提案は次のとおり。押して再生位置を動かすのを基本としたまま、押したままドラッグすれば、再生位置がそのままついてくるようにしたい。タイムラインを再生するアプリでは、よくある動きでもある。

- メディアプレーヤーのシークバー（YouTube など）: 押した位置へ飛び、そのままドラッグできる。ドラッグ中は音を止め、離すと続きから鳴る。
- 波形のプレーヤー（SoundCloud など）: 押した位置へ飛び、ドラッグもできる。
- DAW: ルーラーで再生ヘッドをドラッグできる（Logic、GarageBand）。

この形なら、細い線をつかむ必要がない。押した場所がつかむ場所になる。

## 決定（提案）

1. **マウスとペンでは、押した瞬間に再生位置を動かす。** 押したままドラッグすると、拍の頭ごとについてくる。離したところで止まる。和音の上から押し始めたときは、今どおり固定する。
2. **再生中にドラッグしているあいだは、音を止める。** 離すと、その位置から鳴り続ける。絵が指の下で流れないようにするため。
3. **指では、今どおり押す（タップ）だけ。** 横になぞったときは、本体のスクロール。
4. **ドラッグ中に箱の端へ来ても、自動ではスクロールしない。** 遠くへ動かすときは、帯か、本体のスクロールを使う。
5. 押すだけで同じことができるので、ドラッグだけに頼る操作にはならない（WCAG 2.5.7）。

## 検討した選択肢

- ドラッグ中の音
  - A: 止めて、離したら続きから鳴らす（推奨）。メディアプレーヤーと同じ。絵が動かない。
  - B: 鳴り続け、離したら飛ぶ。ドラッグ中も中央追随で絵が動き、指の下で絵が流れる。
  - C: ドラッグに合わせて、鳴る位置を連続で動かす（スクラブ）。拍ごとに音が切れて、細かく途切れる。
- 指でも、なぞってドラッグできるようにする: 本体の横スクロールとぶつかる。採らない。
- 箱の端での自動スクロール: DAW にはある。今の例の長さでは要らない。必要になったら足す。

## 結果

- 押した場所をつかんで、目当ての拍まで動かせる。押す位置の細かい狙いは要らない。
- 再生中は、ドラッグのあいだ音が止まる。
- 再検討の条件:
  - ドラッグ中も音を聴きたい、という声が出たとき。
  - 箱の外まで引っ張りたい、という声が出たとき。
