# 0066. 再生中の追随は、再生位置を見えている絵の中央に保つ

- 日付: 2026-11-12
- 状態: Accepted（所有者の判断。ADR-0043 の「追随の形」を置き換える。再生中の手でのスクロールは ADR-0068 で置き換え）

## 文脈

長いタイムラインの拡大は、再生位置を中央に保って追随する形だけにすると、所有者が決めていた（BL-127、#352）。

その 2 時間後、タイムラインを横スクロールの 1 本に作り替えたとき（#360、#362、ADR-0043）、追随の形がページめくりに変わった。再生位置が端から 1 割に入ると、左端から 1 割の位置へ飛ばす形である。理由は「絵が止まっている時間が長く読みやすい」という推測だった。#360 で所有者が決めた項目にこの形は含まれておらず、所有者が選んだ記録もない。

所有者は、中央に保つ形に戻すよう求めた。ADR-0043 の再検討の条件（「ページめくりが読みにくいという報告が出たとき」）に当たる。

## 決定

1. **再生中は、再生位置を見えている絵の中央に保つ。** 絵がその下を流れ、線は止まって見える。
   - 中央は、左に重なる行名の列を除いた、絵が見えている部分の中央とする。
   - 先頭と末尾は、スクロールの端で止める。先頭では線が左から中央へ進み、末尾では中央から右へ進む。前後に余白は足さない。
   - 再生中の手でのスクロールは効かない（すぐ中央へ戻る）。
2. **動きを減らす設定（`prefers-reduced-motion: reduce`）の人には、ページめくりを残す。** 再生位置は情報だが、絵全体が流れ続けるのは大きな動きだから。
3. **停止中は今のまま。** 固定した和音があれば中央に置き、なければ動かさない。
4. 絵が箱に収まるとき（広い画面の短い例）は、スクロールがないので、線だけが動く。

## 検討した選択肢

- A: 中央に保つ（採用。所有者の判断）。利点: 再生位置の前後がいつも同じだけ見える。めくる瞬間に全部の位置が変わることがない。欠点: 絵が流れ続ける。
- B: ページめくり（ADR-0043 の形）。利点: 絵が止まっている時間が長い。欠点: めくる直前は先が 1 割しか見えない。所有者の判断と違う。
- C: 前後に余白を足し、先頭と末尾でも中央に置く。利点: 線がいつも中央。欠点: 空白が出て、帯の枠との対応がずれる。

## 結果

- 再生中の絵は、`scrollFor` の `centre` で動く。ページめくりの `page` は、動きを減らす設定のときにだけ使う。
- 再生位置は 25 ms ごとに更新され、スクロールも同じ刻みで動く。実機で絵がかくつくようなら、描画のフレームに合わせる変更を別に入れる。
- 再検討の条件: 流れる絵が読みにくい、酔う、という報告が出たとき。
