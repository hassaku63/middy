# 0020. 分数コードのベースは和声に置き、度数で書く

- 日付: 2026-11-08
- 状態: Accepted（ADR-0012 の補足。所有者の判断は Issue #140）

## 文脈

評価で、分数コードとベースのラインが繰り返し「表せないもの」に挙がった（`I/VII`、`I/3`、卒業ソングの下がるベース、短調のライン・クリシェ、ペダル）。middy の和音は根音と質だけを持ち、ベースはいつも根音だった。

ADR-0012 は、例を和声とグルーヴに分け、ベースの「次の和音を見る」動き（ウォーキング、`approach`）を伴奏の声部（グルーヴ側、BL-086）に置いた。分数コードのベースをどちらに置くかは決めていなかった。

ラベルの `/` は、すでにセカンダリードミナント（`V/V`）に使っている。

## 決定

1. **分数コードのベースは和声の一部。** `Step` と `HarmonyEvent` がベースを持つ。リードシートも「C/E」をコード記号として書く。転回形（`I/3`）は根音が同じでも響きが変わり、ペダル（`IV/1`）は和音が動いてもベースが留まる。これらは和声の性質で、伴奏の型の飾りではない。ウォーキングや経過（BL-086）は、和音の間をつなぐ伴奏の動きとして、グルーヴ側に残す。
2. **ラベルは、`/` のあとに度数を数字で書く。** `I/3`、`IV/1`、`i/#7`、`I/b7`。度数は調の音階に対して書き、ほかのラベルと同じく ♭・♯ は `b`・`#` と書く。`/` のあとがローマ数字ならセカンダリードミナント、数字ならベースなので、字面で区別できる。両方を重ねることもできる（`V7/V/#4` は D7/F#）。調を変えても意味が保たれる。
3. **画面と解説では音名を添える。** 和音名は「C/E」と綴る（`Symbol`）。
4. **伴奏の型の `bass` 声部は、分数コードのベースを弾く。** ベースのない和音では、今までどおり根音。

## 検討した選択肢

- **数字付き低音（`I6`、`I64`）:** 古典の書き方だが、`6` が付加 6 度（`ivm6`）と衝突し、和音にない音のベース（ペダル、経過）を書けない。
- **音名で書く（`C/E`）:** 読みやすいが、調を変えると書き直しが要り、ローマ数字の流儀と混ざる。画面では音名を添えるので、学ぶ人は両方を見られる。
- **ライン・クリシェを伴奏の型にする:** 文法を変えずに済むが、1 つの形しか書けず、転回形やペダルを表せない。必要なら、この決定のあとに足せる。
- **BL-086（ウォーキング）の中で扱う:** ベースの動きを伴奏の飾りにすると、和声の解説（転回形の響き、ペダル）ができない。

## 結果

- 転回形、ペダル、下がるライン、ライン・クリシェ（ベース版）を、1 つの仕組みで表せる。
- 解説（BL-114）は、ベースが和音の音か（転回形）、和音にない音か（ペダル、経過）を区別して述べる。
- 再検討の条件: 内声が動く形（i – i(maj7) – i7 – i6 の上声版）を、ベースではなく和音の質として表したくなったとき。
