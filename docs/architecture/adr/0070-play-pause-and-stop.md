# 0070. 再生／一時停止と、先頭へ戻す停止

- 日付: 2026-11-12
- 状態: Accepted（所有者の判断。ADR-0067 の 5 を置き換える）

## 文脈

これまでのボタンは 1 つで、「再生」と「停止」を切り替えていた（#402 の B）。停止すると、再生を始めた位置へ戻った（ADR-0067 の 5）。

所有者からの指摘は次のとおり。録音機やオーディオ機器のように、再生と停止にはそれぞれ 2 通りの使い方がある。

- 再生: 先頭から再生する、今の再生位置（途中）から再生する。
- 停止: その場で止める、先頭へ戻して止める。

今の形では、その場で止める（一時停止）ことができない。先頭から鳴らすにも、1 小節目を押す必要がある。ただし、部品を増やしすぎないよう、釣り合いを見て決めたい。

検討した形は 3 つ。

- A: 再生／一時停止の切り替えと、停止（■）。
- B: 今のボタンに「先頭へ」を足す。
- C: 停止を 2 回押すと先頭へ戻る（Cubase、Studio One、Ableton の形）。

## 決定

1. **ボタンは 2 つにする。**
   - 主ボタンは、再生 ▶ と一時停止 ⏸ を切り替える。同じ位置・同じ大きさで、今できる操作を出す（#402 の B を保つ）。
   - その横に、控えめな見た目の停止 ■ を置く。
2. **▶ は、今の再生位置から鳴らす。**
   - 再生位置は、一時停止した位置か、押して動かした位置（ADR-0067）。どちらもなければ先頭。
3. **⏸ は、その場で止める。** 次の ▶ は、そこから鳴る。
4. **■ は、止めて先頭へ戻す。**
   - 本体も先頭へスクロールする。ただし、固定した和音があるときは、その和音を中央に置く。
   - 止まっていて再生位置が先頭のときは、押せない。
5. **鳴り終えたら先頭へ戻る**（今と同じ）。
6. **Space と、鳴っている例をもう一度選ぶ操作は、▶ と ⏸ を切り替える。**
7. **状態は増やさない。** 状態は「再生中」と「止まっている」の 2 つのまま。⏸ と ■ の違いは、止まったあとの再生位置だけ。だから、帯と本体の操作の規則（ADR-0067、ADR-0069）はそのまま使える。

## 検討した選択肢

- A: ▶/⏸ と ■（採用）。利点: ボタン 1 つの追加で、4 通りすべてに届く。録音機やメディアプレーヤーと同じ形で、初心者に見慣れている。欠点: ツールバーの部品が 1 つ増える。
- B: ▶/■ と「先頭へ」。欠点: 一時停止がない。
- C: 停止 2 回で先頭へ。利点: ボタンが増えない。欠点: 見ても分からない操作になる。止まっているときにも停止ボタンが要る。
- ■ の戻り先
  - 先頭（採用。メディアプレーヤーと同じ）。
  - 再生を始めた位置（DAW の「停止で開始位置へ戻る」）。区間を聴き直すのには便利だが、先頭へ戻す手段が別に要る。区間を聴き直すときは、本体を押し直すか、解説の枠の「ここから再生」を使う。

## 結果

- 途中で止めて読み、続きから聴ける。
- 先頭から聴き直すのは、■ のあとに ▶ の 2 回で済む。
- 再生の名前は「再生」「一時停止」「停止」の 3 つになる。「停止」は「一時停止」と別の名前として扱う（E2E では完全一致で探す）。
- 再検討の条件: 区間を何度も聴き直す使い方が多く、■ で開始位置へ戻したい、という声が出たとき。
