# 0068. 再生中に手でスクロールしたら追随を止める

- 日付: 2026-11-12
- 状態: Accepted（所有者の判断。ADR-0066 の「再生中の手でのスクロールは効かない」を置き換える）

## 文脈

ADR-0066 では、再生中に手でスクロールしても、絵はすぐ中央へ戻る形にした。

その後、所有者は「他の DAW の仕様を参考にしたい」と考えた。そこで主な DAW を調べた。調べたのは各社のマニュアルの要約とフォーラムで、公式ページの本文までは確かめられていない。

- Ableton Live: 編集したとき、横にスクロールしたとき、ルーラーを押したときに、Follow が一時停止する。
- Descript: 手でスクロールすると自動スクロールが切れる。「再生位置へ戻る」ボタンで戻す。
- Cubase と Logic: 自動スクロールは切り替えで持つ。中央に固定するモードは、Stationary Cursor（Cubase）、Scroll in Play と Catch（Logic）。

手で動かしたのは、何かを見たいからである。それを引き戻すのは、人の操作を打ち消すことになる。

## 決定

1. **再生中に手でスクロールすると、追随を一時停止する。** 絵はその位置に留まり、再生位置は先へ進む。
2. **止まっているあいだは、箱の右上に「再生位置へ戻る」を出す。** 押すと追随に戻る。
3. **次のときも、追随に戻る。**
   - 停止して、もう一度再生したとき。
   - 縮小図の帯を押したとき（帯は「どこを見るか」を選ぶ道具なので）。
4. **本体の絵を押してシークしても、一時停止は解かない。** 押した場所は見えているところだから。
5. **手で動かしたかどうかは、位置で見る。** フックが最後に置いた位置から、2 px より離れていれば、手で動かしたと見なす。ホイール、指、スクロールバー、キーボードのどれでも同じに扱える。
6. 動きを減らす設定のページめくりも、同じ規則に従う。

## 検討した選択肢

- A: 一時停止と、戻るボタン（採用。所有者の判断）。利点: DAW と同じ動きで、先を読める。欠点: 部品と状態が 1 つずつ増える。
- B: 今のまま引き戻す。利点: 状態がない。欠点: 再生中は先を読めない。
- C: 一時停止して、数秒後に自動で戻る。利点: ボタンが要らない。欠点: いつ戻るかが見えず、読んでいる途中で絵が動く。

## 結果

- 再生中でも、先の小節を読める。
- 追随が止まっているかどうかは、ボタンの有無で見える。
- 再検討の条件: ボタンに気づかず「追随しなくなった」という報告が出たとき。
