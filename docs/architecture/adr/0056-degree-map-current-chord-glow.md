# 0056. 度数の地図の今の和音は、外側の枠と動かない光で示す

- 日付: 2026-11-11
- 状態: Accepted

## 文脈

度数の地図は、今の和音（鳴っている、または固定した和音）を、セルの枠の色で示していた。ダークでは白、ライトでは黒。ライトの黒い枠は、すぐ内側の濃い塗り（T の緑、モードの灰）に溶けた。ドリアンでは、今の IV と、使うだけの VII が見分けられなかった（#412）。

今の和音を示す手がかりは、タイムラインと解説の枠とでそろっていなかった。タイムラインは琥珀の縁と ▶／■（ADR-0055）、解説の枠は追従なら琥珀、固定なら青の左端。

所有者は、伸び縮みや明滅のように動く案を却下した。再生中に動いてよいのは、再生位置だけだから。

## 決定

今の和音は、セルの外側に 2 px 離して描く枠と、その色の動かない光（ネオンのような `box-shadow`）で示す。

- 枠と光の色は、追従中は琥珀、固定中は青。タイムラインと解説の枠と同じ。
- ライトでは、枠を地に対して 3:1 以上の濃い色にする。追従は濃い金色 #a16207 で、D の橙 #b45309 は使わない。固定は #2563eb。
- 主和音の内側の線は、光の内側に残す。
- 地図には、光が切れないだけの余白を取る。

## 検討した選択肢

- A: 白と黒の二重の縁。欠点: モードの主和音の内側の線と同じ形になる。
- B: 外側の枠だけ。利点: どの塗りの上でも見える。欠点: 光がある場合よりも目立たない。
- C・E1・E2: 大きさを変える、伸び縮みさせる。欠点: 動きが再生位置と注意を奪い合う（却下）。
- G2: 明滅させる。欠点: 鳴っている間じゅう変わり続ける（却下）。
- G3: 変わった瞬間に強く光って落ち着く。欠点: 変わるたびに一瞬目を引く。
- G1（採用）: B に動かない光を足したもの。

## 結果

今の和音は、3 か所で同じ色の手がかりで結ばれる。動きがないので、`prefers-reduced-motion` の対応は要らない。

D の和音（橙の塗り）の光は、ほかの機能より目立たない。外側の枠と 2 px のすき間があるので、見分けはつく。琥珀や青を変えるときは、ADR-0055 と同じく、地図と札の 3 色から離れているかを確かめる。
