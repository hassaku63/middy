# 0060. 16 分のスウィングを、名前のついたノリとして足す

- 日付: 2026-11-11
- 状態: Accepted（所有者の判断は #308）

## 文脈

ノリ（`feel`）は `straight`・`swing`・`shuffle` の 3 つで、どれも 8 分音符を揺らす。ローファイやヒップホップのビートは、8 分と拍の頭は動かさず、16 分の裏だけをわずかに遅らせる。エンジンには 16 分を組にして揺らす仕組みがすでにある（`Swing.Unit` の `sixteenth`、BL-084）が、選ぶ入口がなかった。

入口を足すのは ADR-0036 で同じ仕組みだと決めていたが、深さの既定値の根拠が要るので見送っていた。調べると、手がかりは研究ではなく制作の慣習だった。ドラムマシンのスウィングは「組の 1 つ目の 16 分の長さの割合」で表し、50 % が真っすぐ、66 % が 3 連になる。ヒップホップでよく使う値は 54〜58 % とされる（#308 のコメントに出典）。所有者は 57 % を選んだ。

## 決定

1. **ノリに `swing-16` を足す。** 16 分音符の組を、比 1.3 : 1 で揺らす。1 つ目の 16 分が組のおよそ 57 % になる（PPQ 480 で、2 つ目の 16 分は 120 から 136 へ動く）。テンポによらない。8 分と拍の頭は動かない。
2. **`swing` と `shuffle` と同じく、6/8 と 12/8 では使わない。** エンジンとインテントが拒む。
3. **スタイルでは、pop と lofi のノリの一覧の末尾に足す。** スタイルのグルーヴ（一覧の先頭から選ぶ）は変わらない。
4. **契約**：`openapi.yaml` の `Feel` の enum に `swing-16` を足す。インテントの enum はカタログから作られるので、自動で増える。
5. **プロンプト**：ローファイやヒップホップのように、8 分は跳ねずに 16 分がわずかによれるイメージで選ぶと書く。評価にローファイ・ヒップホップのケースを足す。

## 検討した選択肢

- A: 名前つきのノリ `swing-16`（採用）。利点：`shuffle` と同じ形で済み、学ぶ人にも名前で見せられる。欠点：`Feel` の enum が増える。
- B: 深さを 54 %（約 1.17 : 1）にする。欠点：真っすぐとの違いが聞き取りにくく、解説で示す揺れが伝わりにくい。
- C: AI に比を数値で書かせる。欠点：AI に音の細部を書かせることになる（ADR-0003 の境界に近づく）。

## 結果

- 16 分の裏がわずかに遅れるローファイやヒップホップのノリを、テンポによらず鳴らせる。
- 57 % は制作の慣習で、測った値ではない。聞いて違和感があれば、比の定数（`swing16Ratio`）だけを変えれば済む。
