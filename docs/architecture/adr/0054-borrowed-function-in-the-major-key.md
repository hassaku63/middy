# 0054. 借用和音の機能の根拠は「長調の中での働き」とする

- 日付: 2026-11-10
- 状態: Accepted（ADR-0050 の根拠の言い方を改める。決めた機能は変えない）

## 文脈

ADR-0050 は、長調の借用和音の機能を「同主短調での働きで決める」とした。そのうえで ♭VI を S にした。

画面の点検（#385 の F2）で、この根拠が画面どうしの食い違いを生むとわかった。

- 短調の例（「窓辺の雨」）では、地図の T の列に VI（F）があり、札も「T · トニック」。短調の機能は度数どおりで、VI はトニックの代理（V → VI の偽終止）として扱う。
- 長調に借りた ♭VI（A♭）は S で、その根拠が「同主短調での働き」になっている。ところが、その同主短調の画面では VI は T。

どちらの読み方にも根拠はある。古典の機能和声では、VI はトニックの代理。日本のポピュラー理論や Berklee では、短調の ♭VI・♭VII もサブドミナント・マイナー。どちらを採るか（短調の VI も S にするか）は流派の選択なので、所有者の判断を待つ（#385）。

## 決定

- 機能はそのまま（♭VI は S、♭VII は次が IV なら S、それ以外は弱い D）。
- 根拠の言い方を改める。借用和音の機能は「長調の中での働き」で決める。長調に借りた ♭VI は、iv の代わりをするサブドミナント・マイナー。
- 解説の文も、両方の画面が食い違って見えないように言う。「長調の中では iv と同じく、短調の色を帯びたサブドミナント（サブドミナント・マイナー）の役をする（短調の中の VI は、トニックの代わりになる）。」

## 検討した選択肢

- 短調の VI（と VII）も S に移す: 日本のポピュラー理論の教本の多くはこの読み方。ただし、すべての短調の例の地図が変わり、V → VI の偽終止の読み方とぶつかる。所有者の判断を待つ。
- ♭VI を T に戻す: ADR-0050 で直した誤り（「調の中心で、落ち着いて聞こえる」）に戻る。

## 結果

- ♭VI の文が、短調の画面の VI（T）と矛盾しない理由を自分で言う。
- 短調の VI の扱いは、所有者の判断まで今のまま。
