# 0004. API 契約は OpenAPI を唯一の情報源とする

- 日付: 2026-11-07
- 状態: Accepted（エラーの形の 1 行は ADR-0030 で置き換え）

## 文脈

フロント（TypeScript）とバック（Go）が別言語なので、リクエスト／レスポンスの形がずれるリスクがある。AI エージェントが片側だけ変更してしまう事故を防ぎたい。

## 決定

- `docs/api/openapi.yaml`（OpenAPI 3.1）を API の正典とする。ハンドラの追加・変更は **同じ PR で** この文書を更新する。
- Go 側は手書きの構造体（`json` タグ）で実装し、ハンドラテストで実際の JSON を検証する。
- TypeScript 側は当面手書きの型（`frontend/src/shared/api`）。エンドポイントが 5 を超えたら `openapi-typescript` で型生成に切り替える（BL-026）。
- エラーは常に `{"error":{"code":string,"message":string}}`。`code` は snake_case の安定した識別子。
- パスは `/api/v1/` 配下。破壊的変更は `v2` を切る（M3 までは発生させない）。

## 結果

- 契約が文書として残り、AI エージェントが両側の整合を確認できる。
- 生成ツールを入れていないため当面は手動同期。PR テンプレートのチェック項目で担保する。
