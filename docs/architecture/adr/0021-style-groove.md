# 0021. スタイルを選び直したときのグルーヴはエンジンが決める

- 日付: 2026-11-08
- 状態: Accepted

## 文脈

例への操作として「同じ進行で、グルーヴだけ替える」（BL-087）を入れる。学習者がスタイルを選び直したとき、どの伴奏・ドラム・ノリで鳴らすかを誰かが決める必要がある。キーの変更（BL-078）と同じく、AI には聞き直さない（ADR-0003: 和声と音はエンジンが作る）。拍子は和声とグルーヴの両方の枠なので、グルーヴを替えても拍子は替えない（ADR-0017）。

## 決定

1. スタイルは拍子ごとにグルーヴを 1 つ持つ（`pattern.Style.Groove(ts)`）。スタイルの一覧の順に見て、その拍子のために書かれた最初の伴奏（なければどの拍子でも使える型、それもなければ `block`）、その拍子の最初のドラム（なければなし）、最初のノリ（複合拍子ではスウィングを除く）。スタイルの一覧は代表的な型を先に書く。
2. 型のカタログ（`GET /patterns`）が、各スタイルの 4/4・3/4・6/8 のグルーヴを返す。画面はそれを見て `from-progression` を呼ぶ。選び方の規則はエンジンだけが持つ。
3. 和声・キー・テンポ・拍子・和音の長さはそのまま。画面は、前後で変わった伴奏・ドラム・ノリだけを述べる。

## 検討した選択肢

- A: 今の型のうち新しいスタイルに合うものは残し、合わないものだけ替える。変化は小さいが、ポップからバラードのように何も変わらないことがあり、「そのスタイルの音」を聴く操作にならない。
- B: 画面がカタログの一覧から選ぶ。規則が TypeScript に移り、テストが Go と二重になる。
- C: AI にグルーヴを聞き直す。遅く、結果が毎回変わり、和声まで変わりうる。

## 結果

スタイルを選ぶだけで、そのスタイルの代表的な音で同じ進行を聴き比べられる。どのスタイルのどのグルーヴも描画でき、スタイルに合うことをテストが検査する。型を 1 つずつ選ぶ操作や、AI がグルーヴを記述する BL-077 が入ったら、この既定の選び方を見直す。
