# 0055. 鳴っている和音は明るさで示し、機能の色を使わない

- 日付: 2026-11-11
- 状態: Accepted

## 文脈

度数の地図と解説の札は、機能を色で示す（T は緑、S は青、D は橙）。タイムラインのコード列は、鳴っている和音を、D と同じ橙で塗っていた。主和音 i が鳴っているあいだも D の色になるので、色で機能を覚えた人には「i はドミナント」と読める。理論の表示と矛盾する。HCI の索引の「強調と手がかり」も、現在位置の強調が機能色と競合しないことを求めている。ライトでは、橙の上の文字のコントラストも足りなかった（コード名 2.05:1）。

## 決定

鳴っている和音は、明るさを反転させて示す。ダークでは明るい灰の塗りに暗い文字、ライトでは暗い灰の塗りに明るい文字にする。縁は、鳴っている音符や打点と同じ琥珀の線（2 px）にする。▶ の印はそのまま残す（色に頼らない手がかり）。機能の色（緑、青、橙）は、地図と札だけが使う。

## 検討した選択肢

- A: 明るさの反転と琥珀の縁（採用）。利点: 1 つの特徴で周囲のどれとも違い、どの機能色とも重ならない。文字のコントラストも足りる。欠点: 塗りの「鳴っている」感は弱まる。縁と ▶ で補う。
- B: D の色を別の色相に変える。欠点: 鳴っている印の琥珀（音符・打点・解説の枠の縁）は画面のあちこちにあり、どの色相を D に選んでも、どこかの「今」の色と紛れやすい。地図の色の慣れも崩れる。
- C: 鳴っている和音の塗りを、その和音の機能の色にする。欠点: モードでは機能の色を出さない（ADR-0045）。色が 2 つの意味（機能と今）を持つ。

## 結果

コード列で機能の色を見ることはなくなり、地図と札の色だけが機能を表す。鳴っている印の色（琥珀）を変えるときは、地図と札の 3 色から離れているかを確かめる。
