# 0012. 例を「和声 × グルーヴ」に分け、「スタイル」で結ぶ

- 日付: 2026-11-08
- 状態: Proposed（所有者の承認待ち。「決めてほしいこと」を参照）

## 文脈

実 API で「スウィング・ジャズの典型的な進行とリズム」を頼むと、和声はジャズとして妥当なのに、ドラムは「8 ビート」「ボサノバ風」になった。リズムが有限のカタログで、和声との整合を誰も検査していないからである。所有者からは、リズムを有限の型にしないこと、和声とリズムを UI でも実装でも区別できるか考えること、を求められている。そこで、音楽理論・作曲・類似アプリを調べた（4 つの調査。出典は末尾）。分かったことは次のとおり。

- **データとしては分けられる。音としては分けられない。** リードシートは、コードと長さだけを書き、グルーヴは「Med. Swing」のような一語で済ませる。Nashville のチャートも、押し（プッシュ）や止めまでしか書かない。アレンジャーキーボード、iReal Pro、Band-in-a-Box、Logic の Session Players は、どれも進行とスタイルを別々に持ち、再生のときに合成する。一方で、コードの変わり目は拍子の感じ方を左右する（Dawe ほか）。また、スタイルが和声の語彙・リズム・ベースの弾き方を束ねている。
- **2 つを結ぶもの:**
  - 和声リズム（何拍で替わるか、強拍に乗るか）
  - スタイル
  - 和音の種類に応じた伴奏の形
  - 押し（コードを 8 分早く弾く）
  - 次の和音を見るベース
  - テンポと和声リズムの釣り合い
  - 拍子
  - 楽団全体の止め
  - フレーズの区切りのフィル
  - スタイルによる和音の色付け（ボサノバで I を 6/9 にする、など）
  - 前の和音からのボイスリーディング
- **類似アプリから学べること:**
  - Band-in-a-Box: 和音の長さ（1・2・4・8 拍）ごとに型を持ち、決定論的に組み立てる
  - Logic の Drummer: 型の名前ではなく「単純 ↔ 複雑」「静か ↔ 強い」の軸でリズムを選ぶ
  - Hookpad: ローマ数字と和音記号を並べ、機能で色分けする
  - Groove Pizza: ステップの格子でリズムを見せる
  - 反面教師: 大量のプリセット（Scaler、Captain Plugins）と、説明のない生成（Suno、Udio）
- **リズムの理論:**
  - 16 分の格子だけでは、スウィング・シャッフル・12/8 を表せない。1 拍の分割数（2・3・4・6）を明示する必要がある
  - スウィングの比率はテンポで変わる（遅いと約 3.5:1、中くらいで 2:1、速いと 1:1 に近づく。Friberg & Sundström）
  - ランダムに揺らす「人間らしさ」がグルーヴを増すという証拠は弱い
  - 今の「シンコペーション」の判定は裏拍の多さを数えているだけで、本来の定義（次の強い拍が鳴らない。Longuet-Higgins & Lee）と違う。誤った解説を出しうる
- **学習の観点:** 1 つの要素だけを変えて、他を固定したときに、学習者はその要素に気づく（Marton の変化理論）。同時に、聴かせる音は常に完全な曲であるべきだ（Lucy Green）。

## 決定（提案）

### 1. 例は「和声」「グルーヴ」「スタイル」の 3 つでできている

| 概念 | 持つもの | 決める人 |
| --- | --- | --- |
| **和声** | 調、和音の列（ローマ数字、和音ごとの拍数、押しの有無）、フレーズ（4 小節か 8 小節。終止の位置） | AI（ローマ数字は検証する） |
| **グルーヴ** | 拍子、小節数（1・2・4）、1 拍の分割数（2・3・4・6）、声部ごとのステップ（アクセント・通常・ゴースト）、ノリ（スウィングの比率と、8 分か 16 分か） | AI（記述として返す。エンジンが検証する） |
| **スタイル** | 合うグルーヴ、和声の語彙の好み、テンポの範囲、ベースの弾き方（ルート、ルートと 5 度、ウォーキング）、ボイシングの方針、和音の色付けの規則 | カタログ（エンジンが持つ） |

- 描画は `Realize(和声, グルーヴ, スタイル) → タイムライン` に一本化する。ADR-0003 は保つ。AI はパラメータと記述だけを返し、音の高さはエンジンが決める。
- AI は最初にスタイルを選ぶ。`Validate` は、グルーヴがそのスタイルに合うかを検査し、合わなければ再試行させる。プロンプトに頼らず、「ジャズの和声に 8 ビート」を決定論的に止める。
- ユーザーがあえて合わない組み合わせにするのは許し、「珍しい組み合わせ」とその理由を示す（ミスマッチも学びになる）。

### 2. グルーヴは型の選択ではなく記述にする（BL-077 の中身）

- AI は格子の記述を返す: 拍子、小節数、分割数、声部（決まった語彙: キック・スネア・クロススティック・ハイハット・ハイハットのペダル・ライド・クラッシュなど）、ステップの強さ、ノリ。必要なら、元にしたカタログの型の id（`basedOn`）も返す。
- エンジンは次を検証する: 範囲、分割数、同時に叩ける数、テンポで見て約 100ms より短い音価。
- エンジンは次を解説する:
  - シンコペーション（正しい定義で、どの拍に対してか）
  - 密度
  - バックビートやハーフタイムの検出
  - ノリ
  - いちばん近いカタログの型からの違い（例: 「ジャズのライドのパターンで、キックを 4 拍目の裏へ動かしたもの」）
- カタログの型は、唯一の選択肢ではなく、名前のついた出発点として残す。
- 「密度 0.6、シンコペーション中くらい」のような数値だけの指定は採らない。どの拍で鳴るかを説明できなくなる。

### 3. ノリは連続値にする

- スウィングは、比率（1.0〜3.0）と、どの細かさを揺らすか（8 分か 16 分）で表す。今の `straight` と `swing` は名前つきの既定値として残す。
- テンポに応じた既定の比率は、傾向として解説する。
- ランダムな揺らぎは入れない。

### 4. 和声の側で直すこと

- 音名は、調の表から決めた文字と変化記号で綴る（BL-079。B♭ を A# と書かない）。
- 和音ごとに拍数を持てるようにする（今は全部同じ拍数）。押しを持てるようにする。
- 機能は、度数だけでなく次の和音も見て決める。短調の VII は、次が III なら V/III、i なら弱いドミナント（バックドアやエオリアンの終止）、i–VII–VI–V の下降なら経過として扱う。
- 9 度・13 度などのテンションは AI が選ばない。スタイルの色付けの規則でエンジンが足し、ローマ数字の分析は 7 度までに留める。

### 5. 伴奏の声部（ベース、コード、ドラム）

- 音の高さは和声から、タイミングはグルーヴから取る。今の `Voice`（`root`、`third` など）の考え方を保つ。
- ベースは次の和音を見る（`approach` の役割を足す）。コードは、前の和音から最小の動きでボイシングを決める（ボイスリーディングの計画）。
- ドラムは、グルーヴとフレーズ（区切りのフィル）だけから作る。

### 6. 画面

- 例のカードと成り立ちを、「コード」と「グルーヴ」の 2 段に分け、スタイルを 1 つの印で示す。タイムラインは 1 本のまま、時間をそろえる。
- 1 つの要素だけを変える操作を足す。キーの変更（済み）、グルーヴの差し替え（同じ進行で）、和声リズムの変更。変えたあとは、変わったことだけを解説する。
- 概念を増やしすぎない（意思 3）。新しい操作は 1 つずつ、画面の約束を更新してから足す。

## 検討した選択肢

- **今のまま（有限のカタログ＋プロンプトでの整合）:** 速いが、ジャズの失敗のような不整合を止められない。所有者の方針にも反する。
- **和声とグルーヴの 2 つだけ（スタイルなし）:** 整合を検査する基準がなく、問題がそのまま残る。
- **AI に音符まで書かせる:** ADR-0003 に反し、説明できない。
- **数値の軸だけでリズムを指定する（Logic の Drummer 風）:** 直感的だが、どの拍で鳴るかを決める決定論的な規則を別に要し、解説できない。将来、格子を作る補助として足す余地はある。

## 結果

- 和声とグルーヴを、それぞれ独立に変えて聴き比べられる。スタイルの整合は決定論的に検査できる。
- インテントのスキーマ、API、評価セットが大きく変わる。スライスに分けて段階的に移る（backlog の BL-077、BL-079、BL-081〜BL-087）。各スライスで評価セットを回す。
- 再検討の条件:
  - 格子の記述で AI の失敗（検証で落ちて再試行になる率）が高止まりする場合は、カタログの型に変化だけを加える方式に戻すことを検討する。
  - 3/4 や 6/8 を入れるときに、拍子をグルーヴに置いた判断を見直す。

## 決めてほしいこと

1. この 3 つの概念（和声・グルーヴ・スタイル）で進めてよいか。
2. 短調の VII の機能を、上の「次の和音を見て決める」規則にしてよいか。
3. 短調の借用和音の書き方。古典の流儀（`VI`）にするか、ジャズの流儀（`♭VI`）にするか。調査では、流派で分かれている。
4. 最初のスタイルの範囲。提案は、ポップ、バラード、ロック、ジャズ（スウィング）、ボサノバ。エンジンが描けないスタイル（ファンクの 16 分、6/8 など）は、描けるようになるまで入れない。
