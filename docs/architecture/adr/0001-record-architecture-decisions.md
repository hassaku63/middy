# 0001. 設計判断を ADR として記録する

- 日付: 2026-11-07
- 状態: Accepted

## 文脈

middy は AI コーディングエージェントが自律的に開発サイクルを回すことを前提にしている。エージェントはセッションをまたいで記憶を持たないため、「なぜそうなっているか」がコードの外に残っていないと、同じ議論を繰り返したり、過去の判断を知らずに壊したりする。

## 決定

Michael Nygard 形式の軽量 ADR を `docs/architecture/adr/` に連番で置く。テンプレートは `0000-template.md`。索引は `README.md`。

## 結果

- 判断の根拠が残り、エージェントが「再検討の条件」を見て妥当性を判断できる。
- ADR を書く手間が増えるが、依存追加や境界変更といった高コストな変更に限定するので許容できる。
