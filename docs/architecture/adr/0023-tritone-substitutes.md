# 0023. 裏コードは `subV7/x` と書き、セカンダリードミナントの一種として扱う

- 日付: 2026-11-09
- 状態: Accepted（所有者の判断は #165。ADR-0012 の和音の語彙を広げる）

## 文脈

評価の「表せないために使わなかったもの」で、ジャズ・ボサノバのケースが繰り返し裏コード（トライトーン代理、♭II7）を挙げた（#165）。所有者は、ローマ数字の記号が増えることを受け入れたうえで、裏コードを足す順番を承認した。

裏コードは、V7（または V7/x）の代わりに、根音が三全音離れた属七を置く和音である。3 度と 7 度（三全音）は入れ替わるだけで同じ音なので、同じように向かう先へ解決し、根音は半音上から向かう先の根音へ降りる。C major の V7（G7）の裏コードは D♭7（♭II7）、V7/V（D7）の裏コードは A♭7 である。

決めることは、記法、向かう先の範囲、同じ音になる別の和音との区別、解説の扱いの 4 つである。

## 決定

1. **記法は `subV7/x`。** x は、`V7/x` と同じく向かう先を調のローマ数字（三和音）で書く（`subV7/I`、`subV7/V`、`subV7/ii`）。属七の代わりなので `subV7` だけを認め、`subV/x` は書けない。
2. **セカンダリードミナントの一種として扱う。** 内部では `Step.Applied` に `Step.Substitute` を加える。分析は機能 D、`AppliedTo` に向かう先を入れ、`Substitute` を立てる。解説は、どの V7 の代わりかを名指しし、次の和音が向かう先なら「解決する」、違えば「かわす」と書く。終止は付けない（セカンダリードミナントと同じ）。
3. **向かう先は長三和音か短三和音。主和音も含む。** `V7/I` は V7 そのものなので書けないが、`subV7/I`（♭II7）は裏コードでいちばん多い形なので認める。減三和音は向かう先にしない。
4. **綴りは向かう先の文字の 2 度上。** C major の `subV7/I` は C#7 ではなく D♭7、E major の `subV7/I` は F7。
5. **同じ音になる借用和音とは、ラベルで区別する。** C major の `bVII7`（借用）と `subV7/vi` はどちらも B♭7 だが、書いたラベルどおりに分析する（V/iv とピカルディの I を区別するのと同じ方法、ADR-0013）。ラベルのない B♭7 は、借用として読む。

## 検討した選択肢

- A: `subV7/x`（採用）。利点: 向かう先が字面でわかり、`V7/x` と並ぶ。ジャズの理論書でも使われる書き方。欠点: 記号が 1 つ増える。
- B: `bII7` のように根音の度数で書く。利点: 短い。欠点: 向かう先が書かれない（`bII7` は I へ、`bVI7` は V へ向かうことが字面からわからない）。`bVII7` などの借用と同じ形になり、意味で区別できない。短調のナポリの bII（三和音）とも紛らわしい。
- C: 書かせず、エンジンがスタイルで V7 を置き換える（テンションと同じ扱い、ADR-0012 の決定 4）。利点: AI の語彙が増えない。欠点: 置き換えは和声の選択で、色付けではない。どこで置き換えるかを学ぶ人に見せられない。

## 結果

- ジャズ・ボサノバの例が、ii7 – subV7/I – Imaj7 のような半音で降りる進行を書ける。解説が、なぜ V7 の代わりになるかを述べる。
- AI が書けるようにするのは BL-129（スキーマ・プロンプト・評価）。語彙が増えると最初の答えの誤りが増えてきたので、評価で再試行の数を見る。
- `subV7/x` の x にスラッシュのベースを付ける書き方（`subV7/I/3`）は、`V7/V/#4` と同じ文法で通る。
