# 0053. 分数コードのある例では、すべての和音のベースを 1 本の線で鳴らす

- 日付: 2026-11-10
- 状態: Accepted（ADR-0020 のベースの鳴らし方を改める）

## 文脈

分数コード（ADR-0020）のベースは、分数コードの下にだけ、3 オクターブ目で鳴らしていた。ベースの声部がある型（`ballad`、`comp`）でも、ベースは 3 オクターブ目に固定だった。

画面の点検（#385 の F1）で、次の食い違いが見つかった。

- 「卒業」の例（`I I/7 vi vi/5 IV I/3 ii7 V7`）の全体の解説は、「ベースが C → B → A → G → F → E → D と順に下がる」と言う。ところが、描かれる最低音は C4、B3、C4、G3、C4、E3、C4、D4 だった。ベースは分数コードの下にしかなく、ほかの和音は声部の動きの都合で転回形の響きになっていた（vi が C・E・A、IV が C・F・A）。
- ライン・クリシェ（`i i/#7 i/7 i/#6`）は「A → G# → G → F#」と言うが、1 小節目にベースがない。
- ベースの声部がある型では、C3 → B3（長 7 度上）→ A3 → G3 と線が跳んでいた。

ベースは最低音のことで、転回形と分数コードの表記は最低音で決まる。下がっていくベースやライン・クリシェは、同じ音域で一歩ずつ動く線である。

## 決定

- 分数コードが 1 つでもある例では、すべての和音にベース（分数コードのベース、なければ根音）を鳴らす（`music.BassLine`）。
- ベースの高さは、前のベースにいちばん近いオクターブにする。範囲は C2〜B3 で、和音の最低音より下。最初のベースは 3 オクターブ目。
- `FromProgression`（ブロックの和音）と `pattern` が同じ線を使う。
  - ベースの声部がある型は、その声部で線を鳴らす。
  - 分散和音は、根音の代わりに線の音から始める。
  - ベースのない型（block、strum、drone など）は、和音の下に線の音を足す。
- 分数コードのない例は、何も変えない。音も SMF も今のまま。

## 検討した選択肢

- 文だけ直す（「分数コードのところでベースが入る」）: 例の目的はその線を聞かせ、見せることで、入門者は画面を信じる。
- どの例にも、ブロックの和音などで根音のベースを足す: 「I の札なのに C/E の響き」も直る。ただし、すべての例の音と SMF が変わる。所有者の判断を待つ（#385 の「決めてほしいこと」）。
- ベースは 3 オクターブ目に固定のまま、分数コードのない和音にも足す: 線が跳ぶ（C3 → B3）ので、一歩ずつ下がる線にならない。

## 結果

- 分数コードのある例では、解説の言うベースの線が、そのまま最低音の線として描かれ、聞こえる。
- 分数コードのある例の音が変わる（ベースの音が増え、高さが線に沿う）。分数コードのない例は変わらない。
