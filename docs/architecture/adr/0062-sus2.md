# 0062. sus2 を 3 度のない和音に足し、3 度のない和音のベースは音程で読む

- 日付: 2026-11-11
- 状態: Accepted（所有者の判断は Issue #450 の C。ADR-0025 の 3 度のない和音を広げる）

## 文脈

評価の「表せないために使わなかったもの」と外部のレビュー（#447）で、sus2 と add11 が挙がった。所有者は sus2 だけを足すと決めた（#450 の C）。add11 はあまり使われず、3 度とぶつかりやすいので見送る。

sus2 は 3 度の代わりに 2 度を鳴らす（C・D・G）。ADR-0025 の sus4 と同じく、長三和音か短三和音かを決める 3 度がない。

足すにあたって、3 度のない和音の分数コードの説明が誤っていた。ベースが和音の 2 番目の音なら「3 度（第 1 転回形）」と呼んでいたが、sus4 の 2 番目は 4 度、パワーコードの 2 番目は 5 度で、どちらも 3 度ではない（`Csus4/F` は「3 度の F」、`C5/G` は「3 度の G」と説明されていた）。sus2 でも同じことが起きる。

## 決定

1. **和音の質 `sus2`（0・2・7）を足す。** 和音名は `Csus2`、ローマ数字は `Isus2`。ADR-0025 の 3 度のない和音の規則をそのまま使う。大文字で書き、小文字は直す。置けるのは、和音の音がすべて調の中にある度数だけ（C major の `IIIsus2` は F# が要るので書けない）。
2. **解説。** 機能は根音の度数のままにする。そのうえで、3 度の代わりに 2 度を鳴らす、開いた響きだと述べる。次の和音が同じ根音で 3 度を持つなら、「2 度が 3 度へ上がり、長調か短調かが定まる」と添える。sus4 と違って「解決」とは呼ばない。sus2 の 2 度は、古典の掛留のように解決を求める音ではないから。
3. **テンションは足さない。** 2 度が 9 度と同じ音なので、スタイルの add9 や 9 度は付けない（`tensionsOf` の既定）。
4. **3 度のない和音の分数コードは、根音からの音程でベースを読む。**
   - sus の 2 度・4 度は、3 度の代わりの音とだけ述べ、転回形とは呼ばない。
   - 5 度は第 2 転回形、7sus4 の 7 度は第 3 転回形。
   - 和音にない音は、ほかの和音と同じく、ペダル・経過音・緊張として読む。

## 検討した選択肢

- A: sus2 を 3 度のない和音として足す（採用）。利点: ADR-0025 の規則と検査をそのまま使える。欠点: ローマ数字の記号が 1 つ増える。
- B: sus2 をスタイルの色付けとして、エンジンが三和音の 3 度を置き換える。利点: AI の語彙が増えない。欠点: どこを開いた響きにするかは進行の選択で、ADR-0025 が sus4 を和音の選択にした理由と同じ。
- C: ベースの説明は位置のまま、3 度のない和音だけ説明を省く。利点: 変更が小さい。欠点: 第 2 転回形のような正しく言えることまで言わなくなる。

## 結果

- AI は `Isus2` を書けるようになる。プロンプトと Schema への追加と評価のケースは、別のスライス（BL-312）で行う。それまで AI は sus2 を書かない。
- 3 度のない和音の分数コードの説明が、構成音に合う。
