# 0050. 長調の借用和音の機能は、同主短調での働きで決める

- 日付: 2026-11-10
- 状態: Accepted

## 文脈

長調の借用和音（BL-094）は、度数の機能をそのまま使っていた。

- ♭VI（C major の A♭）は 6 度なので T になり、「トニック（T）。調の中心で、落ち着いて聞こえる。」と言っていた。
- ♭VII（B♭）は 7 度なので D になり、「トニックへ戻ろうとする緊張を作る」と言っていた。
- ♭III5（E♭5）は 3 度なので T だった。

点検（#371 の C2）で、これらは理論と食い違うとわかった。♭VI は iv と同じ、短調の色を帯びたサブドミナント（サブドミナント・マイナー）の仲間である。♭VII は導音を持たないので、次の和音によって S にも弱い D にもなる。リポジトリの調査（`docs/architecture/adr/0012/harmony.md` の「借用和音」）にも同じことが書いてある。実装がそれと食い違っていた。

## 決定

- 長調の借用和音の機能（`Analysis.Function`）を、同主短調での働きで決める（`functionOf`）。
  - iv と ii° は S（今のまま）。
  - ♭VI は S。文は「iv と同じく、短調の色を帯びたサブドミナント（サブドミナント・マイナー）の仲間。」。
  - ♭VII は、次の和音が IV なら S で「次の IV へ進み、IV と同じサブドミナントの側で働く。」と言う。それ以外は D のままで、「導音を持たないので、V ほど強くは I へ引き寄せない、弱いドミナント。」と言う。
  - ♭III（♭III5）は T のまま。ただし「調の中心」とも「I の代理」とも言わず、「同主短調ではトニック（T）の仲間（短調の i と 2 つの音を共有する）。」と言う。
- 短調の借用和音（ピカルディの I、IV、ナポリ）は変えない。もともと度数の機能が働きと合っている。

## 検討した選択肢

- 借用和音では機能を出さない: 誤りは言わなくなる。しかし、iv と ♭VI がサブドミナントの役をする、という要点が消える。
- ♭VII をいつも S にする（ダブル・プラガルの見方）: ♭VII → I（ロックのよくある終わり方）を、弱いドミナントとして聞く説明も多い。次の和音で分けるのが、調査（ADR-0012 の付録）の結論と合う。

## 結果

- 借用和音の札（T・S・D）と文が、理論と食い違わない。
- 地図（`Overview.Degrees`）は調の和音だけを並べるので、変わらない。全体の解説の機能の流れは、借用和音の新しい機能で数える。
